# Odisha Unveiled

https://www.odishasociety.org/ take the content for the website from here - copy, texts, layout, images

LOVABLE DESIGN SYSTEM PROMPT

Use the attached OSA Brand Visual Identity document as the single source of truth for the visual identity. Apply the following rules consistently across the entire website and UI.

## 1. TYPOGRAPHY

Primary font:

- Mavora Sans

- Use for headlines, hero text, navigation, buttons, section titles, numbers and important UI labels.

- Use the available weight range to create hierarchy.

- Headlines: ExtraBold / Black

- Subheads: Bold / SemiBold

- UI/body: Regular / Medium

Secondary font:

- Naru Sans

- Use for body copy, descriptions, captions and longer text.

- Do not introduce additional Latin typefaces.

Odia:

- Use Noto Sans Oriya for all Odia-script content.

- Never substitute another decorative Odia font.

Maintain a clean, geometric, contemporary typographic system.

## 2. COLOR SYSTEM

Use ONLY the approved OSA palette.

PRIMARY:

- Jagannath Red

- Konark Gold

- Deep Ocean Blue

- Temple Stone

SECONDARY:

- Ivory Sand: #F6F1E7

- Sandstone Beige: #E2D2BB

- Lotus Blush: #E9C8C2

- Palm Leaf Green: #728C69

- Mahanadi Mist: #D6E3EC

- Slate Grey: #6D737A

Color rules:

- Ivory Sand should be the primary light background.

- Deep Ocean Blue and Jagannath Red can be used for strong sections and major brand moments.

- Konark Gold should be used as an accent, not as the dominant color everywhere.

- Secondary colors should support layouts, backgrounds, borders and secondary information.

- Do not introduce random colors.

- Do not use gradients.

Recommended approach:

1 dominant color + 1 supporting color + neutral background + optional accent.

## 3. VISUAL STYLE

The website should communicate:

Odisha + America

Heritage + contemporary

Community + credibility

Warmth + structure

The visual language should feel:

- Premium

- Editorial

- Cultural

- Modern

- Spacious

- Structured

- Human

Avoid:

- Generic Indian visual language

- Generic nonprofit aesthetics

- Generic SaaS/startup UI

- Excessive decoration

- Neon colors

- Glassmorphism

- Heavy gradients

- Overly playful UI

- Excessive rounded cards

## 4. IMAGERY

Use authentic, culturally specific imagery.

Prioritize:

- Odisha architecture

- Jagannath culture

- Konark

- Odisha festivals

- Dance

- Food

- Textiles

- Crafts

- Coastal landscapes

- Community events

- Odisha diaspora / family / community moments

Images should feel:

- Real

- Human

- Warm

- Documentary/editorial

- Premium

Do NOT use generic "Indian culture" stock imagery.

Every cultural visual should be traceable to a specific Odisha object, craft, region, textile, architectural form or tradition.

## 5. CULTURAL MOTIFS

Use three recurring visual motifs:

1. Konark Chakra

   - Heritage

   - Odisha identity

   - Borders

   - Section separators

2. Meghanada Pacheri

   - Community

   - Belonging

   - Structure

   - Cards / containers / framing

3. Sambalpuri Saree / Ikat

   - Borders

   - Decorative strips

   - Event branding

   - Apparel

   - Section dividers

Use these motifs intentionally and sparingly.

Do not turn every section into a cultural pattern showcase.

## 6. PATTERNS

Patterns should communicate the OSA dual identity.

Where appropriate, combine:

- Odisha motifs

- Red

- White

- Deep Ocean Blue / navy

- American-inspired stars and stripes

Patterns should primarily appear as:

- Thin borders

- Section dividers

- Decorative strips

- Small supporting graphics

Do not use dense patterns as full-page backgrounds.

## 7. WEB UI

Create a clean, modern editorial UI.

Layout:

- Large whitespace

- Strong typography

- Clear hierarchy

- Structured grids

- Generous margins

- Strong visual rhythm

Cards:

- Prefer clean geometric containers.

- Use subtle borders.

- Use minimal or no shadows.

- Avoid excessive rounded SaaS-style cards.

- Cultural framing can be used for member/community cards.

Buttons:

- Use Jagannath Red or Deep Ocean Blue for primary CTAs.

- Use Konark Gold selectively.

- Keep buttons clean and geometric.

- Avoid gradients.

Backgrounds:

- Prefer Ivory Sand, white and Sandstone Beige.

- Use Deep Ocean Blue and Jagannath Red for strong feature sections.

## 8. MEMBER / COMMUNITY CARDS

Use the Meghanada Pacheri / Odisha architectural framing concept where appropriate.

Member cards should feel like:

"individuals belonging to one larger community."

Use consistent enclosing shapes and framing across the system.

Do not make every card visually independent.

## 9. ODIA + ENGLISH

Odia should be treated as an identity element, not decoration.

Use Odia for:

- Event titles

- Cultural campaigns

- Signage-style headings

- Social/community communications

For mixed audiences:

- Show Odia with English translation.

Use:

Noto Sans Oriya for Odia

Mavora Sans / Naru Sans for English

## 10. ILLUSTRATION

Any Odisha architectural illustration must respect actual Odisha temple proportions.

Do not create generic temple silhouettes.

Illustrations should be:

- Geometric

- Minimal

- Structurally accurate

- Based on real Odisha architectural forms

Any new graphic element should have a clear cultural source.

## 11. LOGO

Maintain the official OSA logo exactly as provided.

Never:

- Distort

- Stretch

- Add drop shadows

- Add gradients

- Change letter spacing

- Add outlines

- Change approved logo colors

- Place it on a low-contrast background

Maintain the required exclusion zone around the logo.

Minimum logo height:

100px.

Never place typography, imagery, patterns or other graphics inside the logo exclusion zone.

## 12. DESIGN PRINCIPLE

Before introducing any new visual element, ask:

"Can this be traced back to a real Odisha object, craft, region, textile, architectural form or cultural reference?"

If not, do not introduce it unless it is a simple neutral UI element.

The overall design should feel like a contemporary global organization with a strong Odisha identity, NOT a traditional cultural website.

## 13. FINAL UI DIRECTION

Build the website with:

- Mavora Sans + Naru Sans

- Noto Sans Oriya for Odia

- Ivory Sand / white as primary backgrounds

- Jagannath Red + Deep Ocean Blue as major brand colors

- Konark Gold as a controlled accent

- Odisha-specific imagery

- Minimal cultural motifs

- Large typography

- Generous whitespace

- Editorial layouts

- Clean geometric UI

- Strong Odisha + America visual connection

Keep the interface sophisticated and restrained.

When in doubt:

REMOVE elements rather than adding more decoration.

Make sure to download proper fonts and if not found, ask me about it.

Make the design very artistic, a little bit of a brutalism and maximalism. Create images, components, backgrounds and even hover animations that are contextually correct
